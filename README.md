# Microsoft 365 Backup Admin Dashboard

Projeto frontend em Vite + React 18 + TypeScript com Tailwind CSS para um dashboard administrativo de backups do Microsoft 365.

## Requisitos

- Node.js 18+
- npm 9+

## Como rodar

```bash
npm install
npm run dev
```

Abra o navegador em `http://localhost:5173`.

## Rotas principais

- `/login`
- `/connect-microsoft`
- `/dashboard`
- `/tenants`
- `/jobs`
- `/settings`
